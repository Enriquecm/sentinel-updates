# Sentinel updates

Release feed for [Sentinel](https://github.com/Enriquecm/Sentinel), a local-first macOS review command centre.

- `appcast.xml`: the Sparkle feed the app checks (Sentinel → Check for Updates…).
- `Sentinel-<version>.zip`: notarized builds signed with Developer ID.

Published by `macos/scripts/release.sh` from the Sentinel repository and served at https://enriquecm.github.io/sentinel-updates/.
